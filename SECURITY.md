# Security Policy

Beeswax aims to be a secure app that people can rely on to improve their well-being without compromising their privacy, so security is a priority and reported issues will be addressed.

## Reporting a vulnerability

GitHub Private Vulnerability Reporting: https://github.com/flourish-today/beeswax/security/advisories/new

Email: flourish.today@protonmail.com

SimpleX: https://smp17.simplex.im/a#OYNzLgLMY-vsrI69LroxLrhc4xkyLGpT2Q5ygNvoaAc

## Supported versions and response time

Only the latest release gets security fixes. I aim to reply as soon as I can.
